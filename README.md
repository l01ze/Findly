# Findly

Findly is an app that helps you find activities and places around you without having to search through a bunch of different websites.

## What is it?

I made Findly because I feel like there are always places and activities around you that you don't know about. Things like gyms, tennis courts, swimming pools, libraries and community centres can be hard to find.

Findly puts them all in one place so you can search for them, filter them, see them on a map and save the ones you like.

## Features

* Search for places
* Filter by category
* Filter by distance
* View places on a map
* Save places
* Change the app language
* Works on phone and computer

## How I built it

I built Findly using:

* React
* Tailwind CSS
* Leaflet

I also tried to connect it to OpenStreetMap, Overpass and Nominatim to get real places and location data.

I wasn't able to get the APIs working properly before the hackathon deadline, so I used demo data instead to show how the app would work with real data.

## Challenges

The biggest challenge was getting the APIs working.

I spent quite a bit of time trying to connect the app to real location data, but I couldn't get everything working in time. Instead of leaving the app unfinished, I used demo data so I could still build and show the main idea.

I also had to make sure the website worked properly on both phones and computers.

## What I'm proud of

I'm proud that I was able to turn the idea into a working prototype with search, filters, saved places and a map.

Even though the real API isn't working in the current version, you can still see how Findly would work with real location data.

## What I learned

I learned more about React, maps, APIs and working with location data.

I also learned that APIs can take longer to set up than expected, especially when you're trying to build everything during a hackathon. I had to adapt and use demo data so I could actually finish the prototype.

## What's next

The main thing I want to do next is get the real location APIs working so Findly can actually find places near you.

I also want to add more activities and events, improve the recommendations and make it easier to find things happening around you.
